# security policy

## reporting a vulnerability

please do not report security vulnerabilities through public github issues or discussions.

send a private report to `security@tekir.istanbul` with:

- the affected component and version or commit
- reproduction steps or a proof of concept
- the expected and actual behavior
- the potential impact
- any suggested mitigation

avoid including real user data, precise private locations, credentials, access tokens, phone numbers, or other sensitive information. use minimal synthetic evidence where possible.

we will acknowledge the report, assess severity, and coordinate remediation and disclosure. response times are best effort while the project is in early development.

## supported versions

tekir is currently in early development. only the latest state of the default branch is supported.
