# v0.2.0 draft release notes

status: draft for release preparation as of august 6, 2026. this document is not a publication record and does not imply store or web rollout approval.

## highlights

- application-state behavior now follows the approved shared contract across the app: initial read spinners wait 400 ms, retry affordances are consistent, mutation feedback appears immediately, duplicate submissions are blocked, and reduced-motion users get settled non-animated states.
- map, discover, and notifications now cover the approved empty, loading, permission, and error states instead of falling back to generic blanks or missing affordances.
- add-cat preserves typed form data after failures, shows upload progress, and keeps duplicate detection and media steps inside one recoverable flow.
- cat-detail now uses optimistic update saving with rollback on failure, simpler actions, and the approved wider cover-photo presentation.
- splash and brand assets match the approved launch direction, and badge icons meet the contrast correction approved for 0.2.
- cross-screen accessibility regression coverage now checks large text, minimum 44 px tap targets, and reduced-motion behavior across routed app screens.

## user-visible changes

- loading states feel calmer because quick reads no longer flash a spinner.
- save actions acknowledge work immediately and prevent accidental double taps.
- the map and discover flows explain why content is missing and offer retry paths where applicable.
- notifications, profile, badges, and cat detail screens now match the approved 0.2 visual/state contracts more closely.
- add-cat failures are recoverable without re-entering text or reselecting the entire flow from scratch.

## deferred work

- offline cache, connectivity persistence, and submission queues remain out of scope.
- dark mode remains out of scope.
- neighborhood caretaker remains out of scope.
- cat not-found remains out of scope.
- no new help categories or help-contract changes are included.
- unrelated api and data-model changes remain excluded.

## release validation checklist

- automated accessibility regression coverage for cross-screen large text, 44 px targets, and reduced motion: implemented in #119 (`app/test/a11y/cross_screen_a11y_test.dart`).
- manual 0.2 smoke-test evidence and release-build verification: complete, see [v0.2.0-smoke.md](v0.2.0-smoke.md).
- final release publication approval: still required from a human maintainer under the repository workflow.
