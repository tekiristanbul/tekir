# NNNN. short title in lowercase

- status: accepted
- date: YYYY-MM-DD
- source: issue #N, `docs/architecture/<topic>.md`
- supersedes: —

## context

what forced a decision. the constraint, the problem, and anything about the
project's situation that made the obvious answer wrong. state facts, not
intentions.

## decision

what was decided, in the present tense, as a rule the codebase follows.

## alternatives considered

each rejected option and the concrete reason it was rejected. omit this section
entirely if the record's source does not actually say what was rejected — do not
invent alternatives after the fact.

## consequences

what the project now has to live with: the cost, the limitation, the work this
creates, and what would have to happen to reverse it.
