# brand

canonical naming for this product.

- product name: `tekir`
- domain: [tekir.istanbul](https://tekir.istanbul)
- descriptor (optional): "cats of istanbul" — explains what the product does, never used as a substitute for the product name
- repository: [`tekiristanbul/tekir`](https://github.com/tekiristanbul/tekir)

## examples

- correct: "tekir is a community-driven app for tracking istanbul's street cats."
- correct: "tekir — cats of istanbul."
- incorrect: "cats istanbul" or "cats of istanbul" used alone as the product name.
- incorrect: `catsofistanbul`, `cats-istanbul`, or the pre-rename `okanck/catsofistanbul` repository slug — historical only, not in current use.

## where this applies

readme, docs, code comments, commit messages, app titles/descriptions, package manifests, and any other user-facing or repository text. it does not require renaming existing internal identifiers (package names, import paths, database identifiers, environment variables) that were never user-facing.
